# 🚀 Redesign do Site NexTI UniFAP

Este projeto é um **redesign conceitual** do site do **NExTI**, desenvolvido com o objetivo de **prática e aprimoramento** em desenvolvimento e design web.

> ⚠️ **Aviso:**  
> Projeto **apenas educacional**, sem vínculo oficial com o NExTI.

---

## 🎯 Objetivo

- Praticar redesign de interfaces reais
- Evoluir habilidades em **UI/UX Design**
- Trabalhar com **animações modernas para web**
- Criar uma interface **moderna, responsiva e funcional**

---

## 🛠️ Tecnologias Utilizadas

- 💻 HTML5
- 🎨 CSS3
- 🌬️ Tailwind CSS
- 🧠 JavaScript
- ✨ SVG Logo Drawing Animation
- 📱 Design Responsivo
